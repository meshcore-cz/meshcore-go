# wasm-packet-tool

A Svelte web app that encodes and decodes MeshCore radio packet wire formats,
powered by the meshcore-go SDK compiled to WebAssembly.

## Prerequisites

- Go 1.25+
- Node.js 20+

## Running

```sh
make dev
```

This builds the Go WASM module, copies `wasm_exec.js` from your Go toolchain,
installs npm dependencies, and starts the Vite dev server at
`http://localhost:5173`.

For a static production build:

```sh
make build   # outputs to web/dist/
```

## How it works

The Go WASM module (`wasm/main.go`) imports only WASM-safe leaf packages from
the SDK (`meshpkt`, `meshkey`) — never the root package which pulls in serial
and BLE transport dependencies. It exposes a `window.meshcore` object with
functions registered via `syscall/js`:

| Function | Description |
|---|---|
| `encodeGroupText(channelName, sender, text)` | Builds a GRP_TXT packet |
| `encodeDirectText(privHex, peerPubHex, text)` | Builds a TXT_MSG packet |
| `decodePacket(hexStr [, opts])` | Parses any packet; decrypts if keys provided |
| `generateKeypair()` | Creates a fresh X25519 keypair |
| `deriveChannelSecret(name)` | Returns SHA256(name)[:16] as hex |
| `sharedSecret(privHex, peerPubHex)` | X25519 ECDH shared secret |

All byte arrays cross the JS/Go boundary as lowercase hex strings.

## Firmware interop caveat

**Channel messages (GRP_TXT)** use AES-128-ECB + 2-byte HMAC-SHA256 with a key
derived as `SHA256(channelName)[:16]`. This matches the firmware's
`Utils::encryptThenMAC` and fully round-trips with on-air MeshCore packets.

**Direct messages (TXT_MSG)** use X25519 ECDH to derive a shared secret. Keys
generated by this tool are native X25519. Real MeshCore identities are Ed25519
keys converted to Montgomery form for ECDH; verify against the firmware's
`Identity::calcSharedSecret` before expecting cross-device interop on direct
messages.
